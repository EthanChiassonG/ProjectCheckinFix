HighwaymenOfHeaven

===

Reflection Link: https://youtu.be/5A3uhGfaaAg



This is a repository containing my unity project and submission for INFR 1350U Intro to Computer Graphics project submission

Philosophy:

Lighting: The game is to take place in a post apocalyptic world that visually is very dark and red as their sun was the gateway to heaven and now that its gone, its been replaced by a red twisting nether.

I didn't have the time nor nowhere near the art skills to create a full textured cube map in time but I wanted to still translate the idea of it being more dreary, especially since my first phase didn't have that.



Ambiant + Lambet + Sheen: Very similar to class, i wanted to add onto a crowbar but unfortunately I didn't have time to fully implement in scene. Was originally my placeholder texture for my character.



Tiling Offset Dual layered Road and Sand: I made these based off some a previous assignment but heavily altered so that both layers were on one material, these were added to create the illusion of motion and depth since the setting of this scene is on top of a 18 wheeler barreling through a massive highway between planet chunks.





Basic Shader Reconstruction: I made this so that I could implement some of the techniques that I have been learning in the intro to 3D modeling course. Normally we don't create our shaders since the textures tend to already be ready

to implement within scenes after exporting but i wanted to just try and re-create my own version of it so I wasn't just using a default unity asset + I could add and edit the Ambient Occlusion to be more red to match the lighting.





Rim lighting: Very similar to the one we made in class, I was initially going to use it for when the boss fell below a certain threshold of HP but I didn't have the time to model and texture a more complete model for him

so I used it as a signifier since nothing else in the scene is purple and it matches his health bar better.





Outline Overlay: This is a translation the one that we had made for a tutorial into shader form, I made it so that its more obvious to the player that this bottle as apposed to the other falling ones is ok to interact with



Glass: This was just made to add a little bit of depth to the model, I wanted to add a texture input but the bottles are so small and on screen for so little that just keeping them as a bright shiny green actually helped it

read better against the world.

Fire/Shockwave: I made these based off the wave and overlay shaders that we created on week 11, I made these with noise generators after messing around with the different nodes and accidentally discovering the pattern I have now.
I keep it flat and simple because the texturing really reminded me of old videogame lasers and fireballs.



Exhaust VFX: I added these shooting out of the throughout the fight because in the setting of this fight, this is supposed to be an ambush by the character so it helps communicate the chaotic energy of a sudden battle taking place

on a speeding truck, I also added them because It helps frame the battlefield and strengths the illusion of movement with the pavement.

Ember VFX: This was to better communicate the fire as the more dangerous weapon in the bosses arsenal. Helped emphasize the cramped nature of the fight by having the embers spray all around the moveable area even if your not in the

hurt box helps give the attack a sense of power and danger.
